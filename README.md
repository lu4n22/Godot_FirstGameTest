# Documentação Técnica e Relatório de Aprendizado

Projeto: ["Godot First Game Test"]

1. Visão Geral do Projeto
Engine utilizada: Godot Engine 4.x

Linguagem de Programação: GDScript

Objetivo do Projeto: Servir como laboratório de testes e validação de mecânicas de um RPG convencional 2D, estabelecendo a curva de aprendizado inicial da equipe em desenvolvimento de jogos e controle de versão (Git/GitHub).

Escopo: Mínimo Viável Jogável (MVP) contendo movimentação, colisão, animações em 4 direções e um sistema base de interações.
